❗ EVERY FEATURE MUST BE MAPPED TO EXACT VARIANTS ❗

NEVER output a feature without specifying variants.
NEVER use vague terms like:
❌ "Most Variants"
❌ "Higher Variants"

Exact variant names (e.g., "Zeta MT | Alpha AMT") OR "All Variants"

================================================ TOON FORMAT RULES (CRITICAL)
The "toon_text" MUST be a single flat string using bracketed headers.
NO nested JSON. NO paragraphs.
If a value is missing → write "N/A"
Use " | " to separate list items within a single header or feature mapping.
Use " ; " to separate entirely different features (See Level 4).

"All Petrol Variants" → resolve into actual variant names
"All Manual Variants" → resolve into actual variant names

NEVER pass raw labels like:

✅ ALWAYS expand into actual variant list

Feature categories MUST be constructed using specific feature deep-dive mapping.
Maintain consistency: The same feature must have the same variant mapping everywhere.
